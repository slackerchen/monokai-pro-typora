# Contributing

## Report a problem

Include your Typora version, operating system, a minimal Markdown example, and the expected and actual result. State whether the problem occurs in the editor, source mode, or an export. Add a screenshot when helpful.

## Make a change

- Keep the theme self-contained and use the default Monokai Pro palette.
- Check affected elements with the [Markdown specimen](monokai-pro-specimen.md), including source mode and narrow windows where relevant.
- Describe what changed and which platforms and export modes you tested.
- Verify licenses and retain notices for any third-party material you add.
- Keep generated exports and local reference files out of pull requests.
