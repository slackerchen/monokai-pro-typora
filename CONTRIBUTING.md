# Contributing

Thank you for helping improve **Monokai Pro (CE) for Typora**.

## Bug reports

Include the Typora version, operating system, a minimal Markdown example, and a screenshot when useful. Remove personal information from examples and screenshots. Explain whether the issue occurs while editing, in source mode, or during export.

## Changes

- Keep the theme standalone and retain the default Monokai Pro palette.
- Do not add third-party fonts, scripts, icons or CSS without verifying their licenses and retaining the required notices.
- Use `monokai-pro-specimen.md` to check prose, code, tables, tasks, alerts, math and diagrams.
- Check source mode and narrow windows when affected by a change.
- Report the platforms and export modes actually tested. Do not infer native PDF pagination from an HTML preview.
- Do not include local reference themes or generated exports in a pull request.

## Official Community Edition submission

Follow the [official template instructions](https://github.com/monokai-pro/community-edition/blob/main/CONTRIBUTING.md) and [CE publishing rules](https://monokai.pro/contribute).

The template requires README, license and installation documents, plus an app screenshot at least 2048px wide (without window chrome or added graphics) and an app icon at least 1024px wide, centered and padded. The screenshot and icon are not included in this preparation step; verify the app icon's permitted use before adding it. Do not describe this project as officially accepted before acceptance.

Once the complete submission materials are ready, the official process is to open an issue in the Monokai Pro repository with the community repository link. Publication and submission are separate from local file preparation.
